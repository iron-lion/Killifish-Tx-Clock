    Implementation Notes: vs. Costa et al.¶

    This document compares the original aging clock implementation (Costa_et_al/06_AgingClocks/, three Colab notebooks by Lajoyce Mboning) with the re-implementation in src/ and associated run-scripts.

    Legend:

    • ✅ Fixed — brought in line with original
    • 🔧 Intentional improvement — corrects a bug or is methodologically stronger
    • 🎯 Intentional design choice — deliberate divergence with justification
    • ⚠️ Known limitation — noted but not addressed

    1. Source Material¶

    Original This repo
    Format Three Jupyter notebooks (Colab) Python package (src/) + run-scripts
    Authors L. Mboning, E. K. Costa, N. Rappoport AAlab adaptation

    2. Normalization¶

    BayesAge 2.0 — frequency normalization input¶

    🔧 Intentional improvement

    The original passes DESeq2-normalized data into transcriptome_reference(), which then applies frequency normalization — inadvertently double-normalizing. Our version applies frequency normalization directly to raw counts (FrequencyNormalizer), which is methodologically correct.

    EN / PCR — DESeq2 normalization source¶

    🎯 Intentional design choice

    The original loaded a pre-computed R/DESeq2 CSV. Our version reproduces DESeq2 normalization in Python via pydeseq2 with design_factors=["tissue"].

    3. BayesAge 2.0 — Algorithmic Differences¶

    LOWESS smoothing fraction¶

    ✅ Fixed — src/bayesage2.py:BayesAge2Clock.__init__(lowess_frac=0.7)

    Original Before fix After fix
    frac 0.7 0.3 0.7

    frac=0.7 was the single largest driver of different predicted tAge values.

    LOWESS gene pool size¶

    ✅ Fixed — src/bayesage2.py:BayesAge2Clock.__init__(lowess_top_n=500)

    Original Before fix After fix
    Gene pool All ~25K genes 250 500

    Poisson log-likelihood computation¶

    🔧 Intentional improvement

    Original Ours
    Method scipy.stats.poisson.pmf() per gene per age in nested Python loops Vectorized analytic log-PMF over n_genes × n_ages NumPy matrix
    PMF floor 0.001 before log() log(1e-3) clip (mathematically equivalent)

    Spearman correlation¶

    🔧 Intentional improvement — rank-matrix operations over all genes at once vs. per-gene Python loop.

    ⚠️ Spearman p-values are stored as 0.0 placeholders. Not used in any downstream computation.

    M-value range¶

    🎯 Intentional design choice — extended to M = 25–200 (step 5) vs. original 5–100.

    4. Elastic Net — Algorithmic Differences¶

    Hyperparameter search grid¶

    ✅ Fixed — src/elastic_net.py

    Original Before fix After fix
    alpha (values) 8 2 8
    l1_ratio step 0.1 0.2 0.1

    GridSearchCV scaler leakage¶

    🔧 Intentional improvement — scaler fitted per fold; original fitted on full Atlas before GridSearchCV.

    LOSO-CV fold isolation¶

    🔧 Intentional improvement — fresh StandardScaler per LOSO fold.

    5. PCR — Algorithmic Differences¶

    Component selection criterion¶

    🔧 Intentional improvement

    Original Ours
    Range tested All 1…max_components [5, 10, 15, 20] (configurable)
    Selection Visual inspection + query MW p-values LOSO-CV R² on Atlas training data

    Mann-Whitney U is still computed and saved as a diagnostic (*_PCR_query_mw_pvals.csv), but it does not drive model selection.

    6. Sex Stratification¶

    🎯 Intentional design choice — sex-combined models.

    The AAlab and Eugene query datasets have unknown or mixed sex, making sex-stratified prediction impossible.

    7. Batch Correction¶

    🎯 Intentional design choice — ComBat-seq added.

    The original performs no batch correction. Our version applies ComBat-seq (inmoose.pycombat_seq) jointly to Atlas + query, with Atlas as reference batch.
